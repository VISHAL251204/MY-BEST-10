1. Delivery-Level Pressure Index (Pi ∈ [0, 1])

Computed strictly prior to every delivery using cumulative match state (runs_before, wkts_before, balls_remaining, target).

2nd Innings: P_inn2 = 0.45 * S_RRR + 0.30 * S_wkts + 0.25 * S_end
1st Innings: P_inn1 = max(0.85 * S_collapse, 0.80 * S_death) + 0.15 * min(...)
Final Index: P_i = clip( P_inn * (1.15 if Knockout else 1.00), 0, 1 )

High-Pressure Cutoff (Pi ≥ 0.55): Isolates top 18.3% of deliveries (36,750 balls), balanced across 1st innings (18.6%) and 2nd innings (17.9%), triggering a -40.0% drop in league batting average (27.72 → 16.63).

2. 18-Cell Context Benchmarking & Bayesian Shrinkage

Eliminates phase and league bias by comparing every delivery against its exact situational par.

Context Bucket = Comp_Tier (IPL / FM_T20I / Assoc) × Phase (PP / Mid / Death) × Regime
Shrunk Above-Par Metric+ = Σ w_i * (Actual_i - Expected_Bucket) / (Σ w_i + 100)

Competition Weights: IPL = 1.00x, Full-Member T20Is = 0.95x, Associate/Emerging T20s = 0.65x. Empirical Bayes shrinkage (k = 100) prevents small-sample outliers from dominating while rewarding sustained pressure volume.
